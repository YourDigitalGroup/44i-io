Changing an Order in Admin

A quick guide for Account Managers

Almost every change starts the same way: Orders → View on the order → the Services table. Each service has its own buttons; ⇄ Swap Tactic sits above the table. Button names below match the screen.

Watch for a red message. Admin finds cards from the IDs saved on the order (or, for campaigns with no Insertion Order, by searching the client's Trello list). If it can't find a card, it skips that comment and shows the success message with a red warning naming the missed card, for about 14 seconds. Update that card by hand. Some older orders have no saved IO card, so the IO comment and revised IO are skipped. For a service that makes several Trello cards (for example the SEO package), Admin comments on every card in the package and moves their due dates when the end date changes.
Confirm with the AE first. Cancel, Edit, Renew, Swap Tactic and Correct each have a box like "I confirmed this change with the AE." (Correct and Cancel word it for that action). You must tick it before anything saves, and the Trello comment says you confirmed. Approving or rejecting an AE's request doesn't need it.

Changing a service

⇄ Swap Tactic  Client switches tactics, e.g. YouTube TV → Streaming TV
Steps
Pick Current Tactic, New Tactic, Effective Date, New Monthly Budget, New Tactic Runs Through (and a Variant if asked). A preview shows the first month split by days. Click Confirm Swap.
Result
Old tactic ends the day before the effective date (or is cancelled if it hadn't started). New tactic starts on the effective date; its card is reused if the client has one, otherwise built from the service's template.
Watch for
Use this instead of Cancel plus a new Insertion Order, which leaves two lines for one client. The Services table keeps showing the original tactic; the swap is in the order's history.
Correct  AE picked the wrong service
Steps
Pick the Correct service, fill in price, dates, and variant, add a Reason (3+ characters), tick I confirmed the correct service with the AE., click Confirm Correction.
Result
Replaces the service on the same order with no new signature. Order is marked Revised, the right card is built (or reused), and a revised IO is attached. If the card couldn't be built, a Finish Trello card button appears.
Watch for
Not offered for SEO, add-ons, setup fees, hosting, or agent splits. Refused if the old service already has spend, a confirmation, a pause, an open request, or a closed Accounting month. Then Cancel it and use a new Insertion Order.
Cancel  Client stops a service
Steps
Click Cancel on the row, set the Effective Date (starts as today), add a reason if you like, click Submit Cancellation.
Result
Red Cancelled badge; the Renew button goes away. Order totals don't change; they still show what was sold.
Watch for
If the service has a notice period or early-termination fee and the date is too soon, an amber warning appears. It doesn't block you. Past dates are allowed, and the date isn't compared to the service's start, so double-check it.
↻ Renew  Campaign continues past its end date
Steps
Click ↻ Renew. Where the amount is editable, choose Renew as is or Renew with modifications. Enter New End Date (required) and, if modifying, an optional New Monthly Budget (one number). Click Confirm Renewal.
Result
Same line continues with a "Renewed" badge. No new card, no revised IO.
Watch for
It only checks the new end is after the start, not after the current end. No Renew for one-time or cancelled services. An agent/county split has its own Renew, which comments on that agent's card only.
✎ Edit  Change an amount, dates, variant, modules, or quantity
Steps
Ad budget services: Monthly Rate, Whole Campaign Total (split by days), or Custom by Month. Single monthly amount with no catalog price: New amount. One-time or fixed-price: dates and variant only. Click Save.
Result
Order shows a Revised tag with the old amount. Strategist and Accounting update too. A revised IO is attached to the IO card. The tactic card's due date or title only changes if you changed the end date, variant, or modules.
Watch for
A service with more than one amount (e.g. setup fee plus monthly) has no Edit button; ask an admin. Monthly Rate mode doesn't warn if the end is before the start.
✎ Edit Hosting Date
Enter the New Hosting Start Date; the prorated charge is recalculated. Updates Admin and Accounting only. Trello is not changed, so update the card yourself.
✎ Fill in this intake form
Save as Draft sends nothing. Save & Mark Complete comments on that tactic's card and attaches the form (not on the IO card). Nothing is required, and a Complete form can't be reopened.

Requests from the Companion Form

Arrives
You get an email naming the client, the AE, and the services and actions only. Open the Pending Requests tab for dates and amounts, plus the AE's confirmation that the client authorized the change.
Buttons
Approve makes the change now (order, Strategist, Accounting, Trello). Reject opens a note box; closing it without typing still rejects. On a Cancel, Effective date to apply lets you change the date first; the AE is told. Any note you write goes to the AE and the group's IO recipients, so write it for them.
After
When every item in a submission is resolved: one combined comment on each affected card, a revised IO if any item was an Edit or Renew, and one email to the AE and the group's IO recipients (the always-BCC list is blind-copied).
Watch for
Approving a Cancel does not show the notice-period warning, so check the contract first. A Renew or Edit that puts the end before the start is blocked; ask the AE to resubmit or reject.
Campaigns with no Insertion Order on file  (imported or strategist-created)
How
AEs request changes in the Companion Form as usual; they show in Pending Requests as (no IO on file). There is no Cancel, Edit, or Swap button in Admin for them, so requests are how they are changed.
Trello
Admin looks in the client's list for the campaign card (tactic name + client name) and the IO card (named "IO" or "IO - …") and comments on both. If it finds only one, it comments there and names the one it missed. If several could match, it skips that card and tells you.
Watch for
No module or quantity changes, no intake choice, and no revised IO, since there is no signed order.
