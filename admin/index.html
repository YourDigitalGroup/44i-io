Reconcile Trello Lists

Finds clients in Supabase that don't yet have a stored Trello list linked, and suggests a matching list from that client's group's board by name similarity — same matching logic used on the public form's own duplicate-client warning. Confirming a match here means the next IO for that client goes straight to their real list instead of risking a duplicate from an inexact name match. Skip if a client is genuinely new (no list yet) — their first real submission will create one normally.
